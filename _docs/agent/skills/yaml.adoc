[[agent-yaml-workflow]]
== Agent Workflow

. Preserve the distinction between source representation and parsed value when reviewing a YAML change.
. Follow the house style for human-authored YAML even when multiple source representations would parse identically.
. Treat prose inside YAML string nodes as AsciiDoc unless the containing format defines another markup language.
. Use the loader provided by the target project rather than introducing a second YAML-loading path.
. Validate both YAML parsing and the relevant schema or consumer behavior after changing structured data.
