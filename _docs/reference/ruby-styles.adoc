= Ruby Development Style Guide

This guide outlines the Ruby coding styles and conventions used in DocOps Lab projects.


[[automated-style-enforcement]]
== Automated Style Enforcement

DocOps Lab projects using the `docopslab-dev` gem receive shared RuboCop configuration and lint tasks.
Projects may connect those tasks to hooks and CI.
The current canonical lint wrapper reports RuboCop findings but does not yet propagate every false result as a nonzero process status.
Until failure propagation is corrected and covered by subprocess specs, RuboCop rules are configured policy rather than reliable blocking gates.

RuboCop:: Automated code-style checking and correction.
Git Hooks:: Optional pre-commit advice and future pre-push gates.
CI/CD Integration:: Project-owned lint invocation that becomes blocking only when its process status is truthful.

To apply style fixes: `bundle exec rake labdev:heal:ruby`

See {xref_docs_lab-dev-usage_link} for setup details.
